# Quarterly Goals Tracking

A simple checklist to keep each quarterly goal visible. One line per goal — tick the box when the goal is complete.

## Goals

- [ ] Goal 1: Ship the portfolio site redesign
- [ ] Goal 2: Publish two technical write-ups
- [ ] Goal 3: Run a half marathon under 2:15
- [ ] Goal 4: Finish the Rust book

## How to use

1. Check in on each goal at the start of every month of the quarter.
2. Update the corresponding issue with progress notes.
3. Tick the checkbox here only when a goal is fully complete.
